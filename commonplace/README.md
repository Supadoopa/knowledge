# Commonplace

Atomic notes — one idea per file. This is the permanent note layer of the vault. Notes here should be written in your own words, not copied quotes.

## Naming Convention

Use a descriptive phrase as the filename, not a date. Good: `learning-transfers-through-analogy.md`. Bad: `note-2026-04-05.md`.
