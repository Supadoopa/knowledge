# Logs

Daily scratchpad entries. Each file is one day. The format is intentionally loose — capture first, organize later.

## How to use

1. Copy [[utilities/templates/daily-note|the daily note template]] into this folder.
2. Rename the file to today's date: `YYYY-MM-DD.md`.
3. Write freely throughout the day.
