# Outputs

Writing meant to be shared externally — articles, blog posts, essays, threads. Notes here go through a draft → review → published lifecycle.

## Status Tags

| Tag | Meaning |
|-----|---------|
| `status/draft` | Raw, not ready to share |
| `status/review` | Complete enough for feedback |
| `status/published` | Live somewhere externally |
